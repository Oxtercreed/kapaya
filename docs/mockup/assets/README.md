# Landing and catalogue cut-outs

These optimized transparent WebP files are the clean iPhone photography used by
`build.cjs`. They contain no plate, card, tile or baked-in background: the
hero places them directly on its own `#FCE6E9` panel and lets them overhang the
clipped edge. The catalogue plates place the same cut-outs on `#F3F3F3`.

The files are intentionally small and are inlined into `index.html` as base64
data URLs. Keep new photography to the same isolated, evenly lit, borderless
style so the storefront stays visually consistent and self-contained.
